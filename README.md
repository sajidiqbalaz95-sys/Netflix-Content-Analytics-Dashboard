
# 🎬 Netflix Movies & TV Shows Analysis Dashboard

## 📌 Project Overview

This project presents an interactive Excel dashboard for analyzing Netflix Movies and TV Shows data.

The dashboard transforms raw Netflix data into meaningful visual insights using Microsoft Excel features, including Pivot Tables, Pivot Charts, and interactive Slicers.

## 🎯 Project Objectives

- Analyze the distribution of Movies and TV Shows.
- Explore Netflix content across different countries.
- Analyze directors and cast information.
- Compare content categories.
- Build an interactive dashboard for data exploration.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Slicers
- Data Cleaning
- Data Analysis
- Data Visualization

## 📊 Dashboard Features

1. Total Movies KPI
2. Total TV Shows KPI
3. Movies vs TV Shows distribution
4. Country-wise content analysis
5. Director and Cast analysis
6. Interactive Country Slicer
7. Interactive Type Slicer
8. Dynamic charts and visualizations
